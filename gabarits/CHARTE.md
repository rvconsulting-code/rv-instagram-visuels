# Charte visuelle RV Consulting (posts Instagram)

- Format : 1080 x 1350 px (4:5), export JPEG qualité 92, < 8 Mo
- Bleu principal : #3A465C (titres, bandeau, encarts)
- Orange accent : #EB612F (mots-clés du titre, pastilles, badges)
- Fond : crème #F6F1E7, formes rondes #E8DFCC / #EFE7D6
- Polices : Poppins Bold (titres), Inter (texte)
- Logo : gabarits/logo.png (PNG transparent), en bas à droite, hauteur 140 px
- Pas de @ ni d'URL Instagram sur le visuel
- Structure type : pastille thème → titre (2 lignes max, mots-clés en orange) → sous-titre → 2 cartes ou 3 points → encart "à retenir" bleu → logo
- Rendu : Playwright Chromium, viewport 1080x1350, le logo est référencé en chemin relatif (logo.png dans le même dossier que le HTML)
