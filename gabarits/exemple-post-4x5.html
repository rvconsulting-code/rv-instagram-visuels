Financer sa formation

Praticien du bien‑être :
AGEFICE ou FIFPL ?

Vous cotisez chaque année pour votre formation. Encore faut-il savoir à quel fonds vous adresser.

AGEFICE
Souvent les activités de services (massage bien‑être, soins du corps…)
ex. code NAF 9604Z
FIFPL
Souvent les activités libérales (naturopathe, hypnothérapeute, sophrologue…)
ex. code NAF 8690F
!

Le seul juge : votre attestation CFP, à télécharger sur votre espace urssaf.fr. Votre fonds y est indiqué.
